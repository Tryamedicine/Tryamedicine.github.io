Stay strategy

住宿区域怎么选

4–8 人优先 Airbnb / Cabin；2 人时 Hotel / Guesthouse 往往更省心。重点是先锁区域，不急着锁具体酒店。

Stockholm

Norrmalm / Central Station：进城和去 ARN 都最省事。

Lofoten

Svolvær → Leknes/Ballstad → Reine/Hamnøy → EVE。Reine/Hamnøy 那晚值得升级景观 Cabin。

Iceland

Hella → Vík → 冰川区 → Vík/教堂镇 → Keflavík，通过换宿减少回头路。
